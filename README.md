# Sistema de Gestión de Pedidos ED

## Descripción
Sistema desarrollado en Java para simular la gestión de pedidos a domicilio. El proyecto se realiza como trabajo final de la materia Estructura de Datos I.

El sistema permitirá gestionar clientes, comercios, productos, repartidores y pedidos, aplicando estructuras de datos para organizar, consultar y procesar la información.

## Objetivo Académico
Demostrar el uso y aplicación de diversas estructuras de datos lineales y no lineales en un entorno de desarrollo Java puro.

## Estructuras de Datos a utilizar
- **ArrayList:** Para el manejo de listas dinámicas.
- **HashMap:** Para el almacenamiento de datos con clave-valor (ej. diccionarios de productos o comercios).
- **Queue:** Para la gestión de colas de pedidos.
- **PriorityQueue:** Para gestionar pedidos prioritarios.
- **Deque / Stack:** Para el historial de acciones o gestión de pilas.
